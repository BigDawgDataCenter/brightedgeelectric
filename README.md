# Bright Edge Electric · website

The new website for **Bright Edge Electric LLC**, a family-run master electrician serving King & Snohomish County, WA.
Built and run by **Big Dawg Data Center**.

**Status:** private preview. Search engines are blocked (`robots.txt` + `noindex`) until launch, and the live site is still brightedgeelectric.com.

- `index.html`: the whole site (one page for now)
- `assets/`: logo and icon files from the Bright Edge brand kit
- The estimate form is a preview: on launch it sends requests to the owner's inbox and BDDC's lead tracker.
